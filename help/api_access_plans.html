Allowed plans

Choose which plans this API account can use. Plans set customer resource limits and can specify features for new virtual servers.

  • Selected only: allow only the checked plans. An empty selection allows none.
  • All, including future additions: allow every plan, including ones added later.

The default plan must be allowed here. Limits apply to each customer separately; there is no combined resource limit for the API account.

Permission to use a plan does not allow editing it. To create, edit or delete plans, allow the corresponding commands under Allowed commands. Those commands can affect plans outside this selection.
