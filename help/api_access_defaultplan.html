Default plan

Use this plan when a create-domain request creates a top-level virtual server without specifying a plan. A request can choose another allowed plan. Child servers inherit their parent's plan.

Granting create-domain requires a default plan from Allowed plans, even when all plans are allowed.

New customers get their resource limits and features from the plan. Requests cannot override these limits. If the plan has no feature list, the server's default features apply.
