Take over existing DNS zones?
When creating a domain with cloud DNS, this option controls what happens if the zone already exists at the provider. Choose No to refuse domain creation, or Yes to let Virtualmin manage the existing zone.

When moving DNS hosting to an existing cloud DNS zone, No refuses the move before either zone changes. Yes uses the existing records and keeps any provider-specific settings, such as proxy settings. Source records are not copied over them.

When the destination zone does not exist, Virtualmin creates it and copies the source records, regardless of this setting. Providers such as Namecheap require the domain to exist already; otherwise, the move is refused.
