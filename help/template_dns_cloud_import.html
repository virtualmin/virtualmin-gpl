Take over existing DNS zones?
When creating a domain with cloud DNS, this option controls what happens if the zone already exists at the provider. Choose No to refuse domain creation, or Yes to let Virtualmin manage the existing zone.

When moving DNS hosting to an existing Cloudflare zone, No refuses the move before either zone changes. Yes uses the existing Cloudflare records and keeps their proxy settings. Source records are not copied over them.

When moving DNS to a Cloudflare zone that does not exist, Virtualmin creates the zone and copies the source records, regardless of this setting.
