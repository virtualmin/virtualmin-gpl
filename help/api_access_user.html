Username

Choose a name for this integration, such as billing-api. It must not already belong to a Webmin or Unix user. This creates an API login, not a Unix account or a Webmin UI login.

Start with a lowercase letter. Use up to 64 lowercase letters, digits, hyphens or underscores. The names root, admin, sysadm and webmin are reserved.

The username cannot be changed after creation.

Turn off Enabled to block new API requests without deleting the account. Turn it on again to restore access.
