Manage servers this account creates

Let this account manage the virtual servers it creates, for example to suspend or delete them later.

  • On: The account can manage these servers and their child servers using its allowed commands.
  • Off: The account can manage only servers allowed by Existing virtual servers.

If Existing virtual servers allows all servers, this switch makes no difference.

This controls access after creation. The account still needs create-domain permission to create a server. Turning this off leaves existing servers in place.

A replacement API account with the same username does not inherit this access.

Server-wide commands are not limited by this setting.
