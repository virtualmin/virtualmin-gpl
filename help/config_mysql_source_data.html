Include MySQL binary log coordinates in backups?
When this option is enabled, Virtualmin includes the binary log file and position in MySQL database dumps. These coordinates can be used with retained binary logs for point-in-time recovery. The replication statement is written as a comment, so it is not executed when the dump is restored.

Binary logging must already be enabled on the database server, and the backup user must have the required privileges. This option does not enable, disable, retain, or copy binary logs.

This default can be overridden for an individual backup or schedule using the CLI with the --enable-mysql-binlog-coordinates and --disable-mysql-binlog-coordinates command-line flags.
