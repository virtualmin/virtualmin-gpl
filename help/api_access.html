API Access

Use API accounts to let scripts, curl or other tools work with Virtualmin without sharing your administrator login. Each account has its own username and password. You control which commands it can run, which virtual servers it can manage, and which templates and plans it can use.

API accounts have no Unix login and cannot open the Webmin interface or use its general RPC interface. Only the master administrator can manage them.

In Virtualmin Pro, you can give a billing script permission to create virtual servers and nothing else:

  1. Create an API account with a username and password.
  2. Under Allowed commands, check only create-domain. Leave the other settings at their defaults.
  3. Save the account. Use its username and password to call /virtual-server/remote.cgi over HTTPS.

This account can create new virtual servers using the allowed templates and plans. It cannot run other API commands to list, change, suspend or delete servers.

On GPL, API accounts can manage existing servers and change their plans. Creating, cloning, suspending and reactivating servers through an API account requires Pro. Other logins and terminal commands keep their existing permissions.

Root can also manage these accounts from the command line with create-api-account, modify-api-account, list-api-accounts and delete-api-account. Run virtualmin create-api-account --help for options. These commands cannot be called through the HTTP API.
