Allowed commands

Choose which commands this API account can run. The label beside each command names the module that provides it.

  • Allow selected commands: allow only the checked commands. An empty selection allows no commands.
  • Allow all current commands except selected: allow every listed command except the checked ones. An empty selection allows all listed commands.
  • Allow all current commands: allow every command in the current list.

All three modes save the commands allowed when you click Save. Commands added later need permission before the account can use them. When you edit the account again, its allowed commands are checked under Allow selected commands.

Commands limited to allowed virtual servers

These commands check which virtual servers the account may manage. They also check template and plan permissions where needed. create-domain requires an allowed default template and plan.

Server-wide commands

These commands can affect the whole server or grant root access. Virtual server, template and plan restrictions do not limit them. Allow them only for integrations you trust with this access.

The selection mode above applies to these commands too. Allow all current commands includes them.

If a different module takes over a command, this account loses access to it. Review the replacement before allowing it again. Updates within the same module keep the existing permission.

Some commands have more than one name. Allowing or blocking a command applies to all of its names. Each command still checks its own permissions.
