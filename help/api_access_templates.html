Allowed templates

Choose which server templates the account can use. Templates provide settings for new virtual servers.

  • Selected only: allow only the checked templates. An empty selection allows none.
  • All, including future additions: allow every template, including ones added later.

The default template must be allowed here.

Permission to use a template does not allow editing it. To create, edit or delete templates, allow the corresponding commands under Allowed commands. Those commands can affect templates outside this selection.
