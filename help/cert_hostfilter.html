Identifier verification
This setting controls which domain names and IP addresses are included when requesting a certificate from the ACME provider.
  • Request every identifier submits all listed identifiers without a preliminary DNS lookup. The entire request fails if the provider cannot validate any one of them.
  • Skip unresolvable hostnames performs an external DNS lookup first and omits hostnames that do not resolve. IP addresses are not checked by this lookup. The entire request still fails if the provider cannot validate any remaining identifier.
  • Use only validated identifiers allows the provider to omit identifiers that it cannot resolve or validate and issue a certificate for the successful subset.

The last option may produce a certificate that does not cover every requested name or IP address. Correct the DNS or validation problem before relying on an omitted identifier.
