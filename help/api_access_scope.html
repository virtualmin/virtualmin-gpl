Existing virtual servers

Choose which virtual servers the account can manage with its allowed commands. Access to a server includes its child servers.

  • Selected only: allow the checked servers. With no servers checked, this list grants no access.
  • All, including future additions: allow every server, including servers created later by other accounts.

Manage servers this account creates

Turn this on to also allow access to servers created by this account. Creating a new top-level virtual server requires create-domain permission, but does not require access to an existing server.

These restrictions apply to commands limited to allowed virtual servers. They do not limit server-wide commands.
