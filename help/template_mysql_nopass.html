Database password for new domains
This option sets the initial MySQL and PostgreSQL password for new virtual servers, and whether it changes when the administration password changes. Sub-servers use the database login of their parent virtual server.

When the password is synced with the administration login, changing the administration password also changes the database password, unless a separate database password has been set.

When it is the same as the initial administration login, the database password starts out as the administration password, but later administration password changes leave it unchanged.

When it is generated randomly, each new virtual server gets its own random database password, which administration password changes leave unchanged.

Virtual servers that store hashed passwords always get a random database password, so this option does not apply to them.
