API password

Use a unique, randomly generated password of at least 24 characters. Webmin's password rules also apply. Store the password securely in the integration. Do not put it in URLs, JavaScript sent to browsers or files committed to Git.

When editing an account, select Leave unchanged to keep its password. To replace it, select Set to .. and enter a new password, then update the integration to use it. New accounts require a password.

Use the account's username and password with HTTP Basic authentication over HTTPS to call /virtual-server/remote.cgi. Verify the server's TLS certificate.
