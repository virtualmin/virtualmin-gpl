Hosting for DNS records
If you have other Cloud DNS providers configured, this option allows you to move the DNS hosting for this domain between them, or from local hosting to the cloud. Moving DNS hosting deletes the zone from the old provider and normally copies its records to the destination. Moving to local hosting deletes the existing cloud zone.

If the destination zone already exists at the cloud provider, the template's Take over existing DNS zones? option controls the move. When enabled, Virtualmin manages the existing records and keeps any provider-specific settings, such as proxy settings. Source records are not copied over them. When disabled, Virtualmin refuses the move before changing either zone.

Update the domain's nameservers at its registrar as needed when moving DNS hosting.
